# Тест-кейсы приложения «Ясна» для Android

Актуально для сборок 2.x (обновляется по мере волн; впервые — 2.0/11) · прогон: стенд-эмулятор Android + браузерная
витрина на трёх вьюпортах (360×800, 393×873, 412×915) в обеих темах.
Статусы: ✅ проверено автоматически/на стенде · 👁 проверено глазами по
скриншоту · ⏳ проверить на живом устройстве.

## 1. Сквозная навигация (наббар)

| № | Сценарий | Ожидание |
|---|----------|----------|
| 1.1 | Открыть каждый экран: Главная, Игра, Уроки, Разбор, Профиль, Рейтинг, Тренажёры, Переговоры, Круг, 404 | Внизу один и тот же наббар из 5 разделов; сайтовой шапки (.ynav/.dp-header) нет |
| 1.2 | Активный пункт | Главная→«Главная», duel/rating/krug→«Игра», learn/trainers/negotiations→«Уроки», konstruktor→«Разбор», profil→«Профиль» |
| 1.3 | Тап по каждому пункту наббара с каждого экрана | Переход на соответствующий экран, без 404 (включая глубокий путь games/krug → ../../) |
| 1.4 | Открыть клавиатуру (поле имени в Профиле) | Наббар прячется, не всплывает над клавиатурой |
| 1.5 | Низ контента на каждом экране | Последний элемент не прячется за наббаром (padding-bottom ≥70px) |
| 1.6 | Модальные окна (вход в duel, онбординг переговоров) | Модалка ПОВЕРХ наббара, наббар не торчит сквозь неё |
