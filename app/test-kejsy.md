# Тест-кейсы приложения «Ясна» для Android

Актуально для сборок 2.x (обновляется по мере волн; впервые — 2.0/11) · прогон: стенд-эмулятор Android + браузерная
витрина на трёх вьюпортах (360×800, 393×873, 412×915) в обеих темах.
Статусы: ✅ проверено автоматически/на стенде · 👁 проверено глазами по
скриншоту · ⏳ проверить на живом устройстве.
