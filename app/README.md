# Ясна — приложение для Android

Обёртка Capacitor вокруг витрины сайта. Содержимое лежит **внутри** приложения,
поэтому уроки, конструктор и Партия работают без сети; в сеть приложение ходит
только за прогрессом, рейтингом и спаррингом.

```
app/
├── sobrat-vitrinu.mjs   что и почему берётся из docs/ (и что не берётся)
├── pribavka.js          кнопка «назад», строка состояния, знак о пропаже сети
├── capacitor.config.json
├── www/                 собирается скриптом, в git не хранится
└── android/             проект Android
```

Цель сборки — **API 36 (Android 16)**, минимум — API 24 (Android 7).
С 31 августа 2026 Google Play принимает только API 36; Capacitor 8 ставит его
по умолчанию, поэтому взята восьмая версия, а не седьмая (та нацелена на 35).

## Что нужно один раз

**Node 22.** Capacitor 8 требует именно его; на машине лежит в `~/.local/node22`.

```bash
export PATH="$HOME/.local/node22/bin:$PATH"
```

**JDK 17 и инструменты Android** — уже скачаны в `~/.local/android-build`.

```bash
export JAVA_HOME="$HOME/.local/android-build/jdk-17/Contents/Home"
export ANDROID_HOME="$HOME/.local/android-build/sdk"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

**Лицензии Android SDK.** Это согласие с условиями Google, и принять его должны
вы, а не кто-то за вас:

```bash
yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-36" "build-tools;35.0.0"
```

Около гигабайта. Версии не выдуманы — это ровно то, что запросил Gradle при
пробной сборке:

```
Failed to install the following Android SDK packages as some licences have not been accepted.
     build-tools;35.0.0 Android SDK Build-Tools 35
     platforms;android-36 Android SDK Platform 36
```

Дальше сборка идёт сама.

## Собрать

```bash
cd app
npm install
npm run apk     # отладочная APK — поставить на телефон и попробовать
npm run aab     # выпуск для магазина (нужен ключ, см. ниже)
```

Готовое лежит в:

```
android/app/build/outputs/apk/debug/app-debug.apk
android/app/build/outputs/bundle/release/app-release.aab
```

Поставить на телефон, подключённый по USB:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

`npm run sync` пересобирает `www/` из `docs/` и переносит в проект — делайте
после любой правки сайта.

## Ключ подписи

**Создаёте вы, и он не проходит через переписку.** Магазин принимает обновления
только за той же подписью, что и первая версия: потеряете ключ — обновить
приложение будет нечем, придётся публиковать заново, с нуля отзывов.

```bash
keytool -genkeypair -v \
  -keystore ~/yasna-release.jks \
  -alias yasna \
  -keyalg RSA -keysize 4096 -validity 10000
```

Затем создайте `app/android/keystore.properties` — он в `.gitignore` и в
репозиторий не попадёт:

```properties
storeFile=/Users/avva/yasna-release.jks
storePassword=…
keyAlias=yasna
keyPassword=…
```

Копию `.jks` — в надёжное место вне git. Без файла `keystore.properties`
выпуск собирается неподписанным, а отладочная APK — как обычно.

## Что в приложение не поехало и почему

| Что | Почему |
|-----|--------|
| `admin.html` и его скрипты | рабочий инструмент владельца, а не часть продукта |
| `games/duel/v2` | тянет babel-standalone с чужого CDN (3 МБ) и компилирует JSX в браузере |
| `core/gate.js` | замок держит сайт на время стройки; в приложении человек увидел бы окно служебного пароля и не смог бы его пройти — хранилище у приложения своё |
| `sw.js`, `offline.html` | внутри приложения файлы и так местные; работник только путал бы обновления |
| `CNAME`, `robots.txt`, `.nojekyll` | служебное для GitHub Pages |

Сборщик проверяет сам: если в витрине останется ссылка на чужой сервер, он
скажет об этом и завершится с ошибкой.

## Что в приложении работает иначе

**Вход через Telegram — только на сайте.** Виджет привязан и к домену в
BotFather, и к браузерному окружению. В приложении вместо кнопки стоит строка
«Вход через Telegram доступен на сайте», а вход по почте работает как обычно.

**`/profile` отдаёт 403.** Это единственный эндпоинт с настоящей проверкой
Origin, и в белом списке только `https://avvacumrechevoi.github.io`. У
приложения origin свой (`https://localhost`), поэтому блок профиля игрока не
работает. Починить правкой нельзя: исходника функции `yasna-profile` в
репозитории нет, она живёт только в облаке. Это же сломается и на сайте, когда
поднимется `yasnalab.ru`, — см. `PERENOS_DOMENA.md`.

**Гостевой прогресс не переносится с сайта.** У приложения своё хранилище:
человек, вошедший на сайте, в приложении окажется гостем. Вход по почте это
решает; для гостя — нет, и при переустановке приложения гостевой прогресс
пропадёт безвозвратно.

## Перед подачей в магазин

1. Поднять `yasnalab.ru` — без рабочего домена нет ни политики
   конфиденциальности по ссылке, ни поддержки.
2. Написать политику конфиденциальности: RuStore и Google Play требуют ссылку
   на действующую страницу. В проекте её сегодня нет.
3. Решить с `/profile` — иначе в приложении будет видимо неработающий раздел.
4. Возрастная маркировка и описание карточки.
5. Ключ подписи (см. выше) и учётная запись разработчика.

Где публиковать и чем это грозит российскому владельцу — в разборе
`/Users/avva/Downloads/Ясна книги официалные` (отчёт «Ясна на Android»).
Коротко: RuStore — регистрация и публикация бесплатно; Google Play для
владельца с российскими реквизитами практически закрыт.
